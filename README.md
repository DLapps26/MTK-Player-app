# MTK PLAYER


**MTK Player** is a modern external media player designed for **Android TV**, specifically optimized to address video playback issues commonly found on devices powered by **MediaTek chipsets**.

Many Android TV models — including Philips, Sony (select models), TCL, Hisense, Xiaomi, and some Amazon Fire TV units — may struggle with complex video formats such as hybrid **Dolby Vision + HDR10** streams, mixed metadata, or unusual codec combinations.

MTK Player focuses on delivering **smoother**, **more stable**, and **more reliable** playback in these demanding scenarios.



## 🎬 Main Features

- Optimized video playback for Android TV  
- Fast, clean, remote‑friendly interface  
- External player support  
- Integration with compatible media servers (Jellyfin, Emby)  
- Automatic subtitle and audio track selection  
- Enhanced compatibility for hybrid Dolby Vision / HDR10 videos on MediaTek‑based devices  



## 🌈 Premium Feature: Dynamic Theme

The **Dynamic Theme** enhances the viewing experience by adapting the interface colors to match the currently playing media.  
This creates a more immersive and visually coherent environment.

The color palette is generated using artwork provided by your media server (Jellyfin / Emby), producing a unique theme for each movie or episode.



### ✔ Compatibility

**Compatible:**  
- Jellyfin  
- Emby  

**Not compatible:**  
- Apps that do not provide metadata or artwork (e.g., TiviMate)



### ❓ Why some apps are not supported

Some applications only pass the raw video stream URL without any metadata or images.  
Since Dynamic Theme relies on artwork to generate its color palette, it cannot function without these assets.

Additional compatibility may be added in the future.
